## Install

<CodeGroup>

```bash npm
npm install example-package
```

```bash yarn
yarn add example-package
```

</CodeGroup>

## First steps

<Steps>
  <Step title="Create a project">
    Run `example init` in an empty folder.
  </Step>
  <Step title="Edit the settings">
    Open `example.config.json` and set a name for your project.
  </Step>
  <Step title="Run it">
    Run `example start` and open `http://localhost:3000`.
  </Step>
</Steps>

<Note>
  This page is only an example. Replace the commands with your own.
</Note>
